# Arcopolis — GUI-equivalence audit of the command/interaction surface

**Status: standing reference (2026-06-13).** A single table classifying every Arcopolis backend
command/interaction surface against the project's non-negotiable rule — _the GUI behavior is the
engine behavior is the behavior_ (AGENTS.md). Produced by an adversarial multi-agent sweep after a
fidelity-subset gap (directed examine shipped 4 of 8 directions) was caught in review.

## The standard

A surface **passes** (earns a "faithful" verdict) only when it reproduces the GUI behavior for what
it claims to do — including any **deliberate, source-justified exclusion that is recorded** (e.g.
examine excludes vertical because `game::examine` passes `allow_vertical=false`). Partial coverage of
a GUI primitive while presenting _as_ the primitive is a **violation**, not an "acceptable
limitation," regardless of documentation — disclosure is not compliance. A wholly-unbuilt command
(talk, pickup, open/close) is honest **backlog**, distinct from a violation, because it does not
present as a complete primitive it then under-delivers.

The adversarial completeness pass confirmed the backend's **input verb set is exactly
`{wait, move, examine}`** — no additional input verb hides behind a misleading name; export/snapshot
modes are queries, not commands.

## Open items this audit records (so they are not silent)

- **`move` vertical** (`move_up/down`): the `game::vertical_move` primitive — its own future command,
  not a widening of planar move (it can open its own prompts: stair/ramp selection).
- **`examine` interaction depth**: acting on menu targets (NPC talk/attack/swap, pickup-as-an-action,
  computer use) — needs a prompt-aware protocol (doc 25 Option C), deferred.
- **`open`/`close`/`smash`** verbs — the near-free examine follow-ups.
- ~~**Frontend diagonal click-move**~~ — **closed (Spike 11B)**: the click mapping + 3×3 d-pad now
  cover all 8 neighbors and a Move/Examine selector adds 8-way-plus-`here` examine; the frontend row
  above is now **faithful** for the planar move/examine surface. See doc 29.
- **`npctalk` raw dialogue read** (`src/npctalk.cpp`) — a direct `get_input_event` reader not reachable
  today (examine's NPC menu auto-cancels first); the future `talk` verb must guard it before exposing
  dialogue (recorded in [27_BACKEND_RAW_WAIT_GUARD.md](27_BACKEND_RAW_WAIT_GUARD.md)).
