## 4. Gaps and risks

1. Prompt-support risk: Spike 20 and Spike 21 closed the known silent
   `query_popup` and `uilist` prompt-default holes, but fail-loud detection is
   not prompt support; NPC menus, generic uilists, generic query popups, and
   `inventory_selector` remain unsupported surfaces
   (`docs/arcopolis/ARCOPOLIS_STATE.md:619`,
   `docs/arcopolis/43_SPIKE21_UILIST_UNEXPECTED_PROMPT_FAIL_LOUD.md:91`,
   `docs/arcopolis/43_SPIKE21_UILIST_UNEXPECTED_PROMPT_FAIL_LOUD.md:150`).
2. Renderer/test_mode risk: headless backend paths must skip curses window
   creation, and the risk map calls out test_mode/render hazards
   (`docs/agent-map/04_RISK_ZONES.md:16`, `src/ui.cpp:633`,
   `src/popup.cpp:264`).
3. Coordinate, mapbuffer, and reality-bubble risk: export windows are shared
   across entities, but the broader map/reality-bubble area is large
   (`src/arcopolis_export.cpp:180`, `docs/agent-map/01_MODULES_THIN_INDEX.md:34`).
4. Fixture brittleness: witnesses depend on external fixture saves and their
   cataloged roles rather than repo-tracked save data
   (`docs/arcopolis/TEST_FIXTURES.md:1`, `docs/arcopolis/TEST_FIXTURES.md:22`).
5. Save/load migration risk: serialization compatibility is a named risk zone,
   and fixture-world loading is not currently its own migration test suite
   (`docs/agent-map/04_RISK_ZONES.md:28`, `tests/savegame_test.cpp:17`).
6. Long-running simulation risk: live mode proves a short sequence, while the
   turn loop continues through many world-simulation responsibilities after
   player action (`docs/arcopolis/live_protocol_regression.ps1:164`,
   `src/game.cpp:2149`).
7. Frontend contract drift: harness/prototype consumers exist, but the state doc
   is still the contract authority rather than generated schema enforcement
   (`docs/arcopolis/ARCOPOLIS_STATE.md:146`,
   `tools/arcopolis_frontend/prototype_server.py:4`).
8. Broad subsystem risk: the agent map is a practical partial map, not an
   exhaustive architecture document (`docs/agent-map/README.md:3`).

## 5. Coverage measurement recommendation
